Project 1 - AI Image Generator

About the Project

AI Image Generator is a web application that allows users to generate images using text prompts.

The project uses MERN Stack technologies along with AI image generation.

Features

  • User Registration
  • User Login
  • Protected Routes
  • AI Image Generation
  • Prompt History
  • Download Image
  • Like Image
  • Delete Image
  • Trending Suggestions

Technologies Used

  1. React
  2. Node.js
  3. Express.js
  4. MongoDB
  5. JWT
  6. Cloudinary
  7. AI Image Generation API
